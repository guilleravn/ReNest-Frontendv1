# ReNest Frontend

Next.js frontend for ReNest. Consumes the ReNest-Backend REST API (separate repo).

## Getting started

```bash
npm install
cp .env.example .env.local   # then adjust API_URL if needed
npm run dev                  # http://localhost:3001
```

ReNest-Backend is expected on `http://localhost:3000`.

See [CLAUDE.md](CLAUDE.md) for commands and conventions, and [docs/](docs/) for details.
